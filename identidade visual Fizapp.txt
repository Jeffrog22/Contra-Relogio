# IDENTIDADE VISUAL — Design System para replicar

## Stack
- React + Tailwind CSS (darkMode: 'class')
- Sem design tokens CSS — tudo via classes Tailwind
- Dark mode: prefixo `dark:` no mesmo elemento

## Fonte
- `font-family: Inter, system-ui, Avenir, Helvetica, Arial, sans-serif`
- Carregada via CSS (não Google Fonts)
- `-webkit-font-smoothing: antialiased`

## Spacing & Radius

### Padding global
- Página: `p-6`
- Modal body: `p-6` ou `px-6 py-4`
- Card: `p-6`

### Gap padrão
- Sidebar nav: `gap-3` (icon + texto)
- Grid cards: `gap-4` (desktop), `gap-3` (pequeno)
- Action buttons: `gap-2`
- Inline: `gap-1.5` ou `gap-2`

### Border radius
| Uso | Classe |
|-----|--------|
| Inputs, botões, modais | `rounded-md` |
| Cards | `rounded-xl` |
| Home cards | `rounded-xl` |
| Pills, badges, chips | `rounded-full` |
| Login inputs | `rounded` |
| Modais | `rounded-lg` |
